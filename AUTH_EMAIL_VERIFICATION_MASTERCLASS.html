01 Authentication Architecture & Core Concepts
Theory & Flow

Kissi bhi production-grade website (jaise Instagram, Netflix, ya PulseChat) me user management 4 main pillars par tiki hoti hai:

1
Identity Creation (Registration): User apni details deta hai (Email, Password, Username).
2
Verification (Email OTP): Confirm karna ki email sach me usi user ka hai taaki bots aur fake spam accounts na banein.
3
Authentication (Login): Password check karke user ki identity verify karna.
4
Authorization (Session / JWT Token): User ko ek Digital ID Card (Token) dena taaki har agle request par baar-baar password na mangna pade.

🔑 Sessions vs JWT (JSON Web Tokens) - Konsa Kab Use Karein?

Feature Traditional Session (Cookie) JWT (JSON Web Token) - Recommended
Store Kahan Hota Hai? Server memory / Redis me Client ke pass (LocalStorage / HttpOnly Cookie)
Server Load Zyaada (Har request par DB lookup) Zero (Stateless — Token decrypt karke verify hota hai)
Mobile App & Cross-Domain Difficult configure karna Super Easy (React Native, Android, Web sabme chalta hai)

🔒 Password Hashing (Bcrypt) — Sabse Badi Galati Jo Kabhi Mat Karna

⚠️ RULE #1: Kabhi bhi user ka Password Plain-text me save mat karna! Agar aapka database kabhi leak ho gaya, to saare users ke passwords leak ho jayenge. Isliye hum Bcrypt use karte hain jo password ko One-way Cryptographic Hash me convert kar deta hai.

Plain Password: mysecretpassword123
Bcrypt Hashed Password: $2a$10$vI8aWBnW3fID.ZQ4/zo1G.q1lRps.9cGLcZEiGDMVr5yUP1KUOYTa

Bcrypt ki khasiyat ye hai ki is hash se wapas original password nikalna mathematically impossible hai. Jab user login karta hai, hum bcrypt.compare(inputPassword, storedHash) se verify karte hain.

02 Database Schema Design (Mongoose / MongoDB)
Database Layer

Email verification system ke liye aapke User Schema me ye specific fields hona zaroori hai:

// models/User.js
const mongoose = require('mongoose');

const userSchema = new mongoose.Schema({
  id: { type: String, required: true, unique: true }, // Custom clean ID jaise user_abc123
  username: { type: String, required: true, unique: true, lowercase: true, trim: true },
  email: { type: String, required: true, unique: true, lowercase: true, trim: true },
  displayName: { type: String, required: true, trim: true },
  passwordHash: { type: String, required: true },

  // --- Email Verification Fields ---
  isEmailVerified: { type: Boolean, default: false }, // Default hamesha false hoga!
  otpCode: { type: String, default: null },           // 6-digit OTP code (e.g. "849201")
  otpExpires: { type: Date, default: null },           // Expiry time (current time + 10 mins)
  
  // --- Security & Activity Tracking ---
  lastLogin: { type: Date, default: null },
  createdAt: { type: Date, default: Date.now }
});

module.exports = mongoose.model('User', userSchema);
💡 Pro Tip: Lowercase & Trim Zaroor Lagayein! Agar user register karte waqt John@Example.com likhta hai aur login me john@example.com likhta hai, to bina lowercase: true ke matching fail ho jayegi!
03 Email Delivery Engine (Brevo API & SMTP)
Mailing Layer

Email bhejne ke do tareeqe hote hain:

  • 1. SMTP (Nodemailer): Standard email protocol (Gmail SMTP, Brevo SMTP, Amazon SES).
  • 2. HTTP REST API (Brevo / Resend): Cloud platforms (Render/Heroku) par SMTP ports block ho sakte hain, isliye REST API 100% reliable hoti hai.

Professional OTP Email Sender Utility

// utils/mailer.js
const nodemailer = require('nodemailer');

// 1. Brevo Direct API Fallback (Best for Cloud Deployments like Render)
async function sendViaBrevoApi(toEmail, otpCode, appName = 'MyAwesomeApp') {
  const apiKey = process.env.BREVO_API_KEY;
  if (!apiKey) throw new Error('BREVO_API_KEY is not configured');

  const response = await fetch('https://api.brevo.com/v3/smtp/email', {
    method: 'POST',
    headers: {
      'accept': 'application/json',
      'api-key': apiKey,
      'content-type': 'application/json'
    },
    body: JSON.stringify({
      sender: { name: appName, email: process.env.SMTP_FROM || 'no-reply@myapp.com' },
      to: [{ email: toEmail }],
      subject: `${otpCode} is your verification code for ${appName}`,
      htmlContent: getOtpHtmlTemplate(otpCode, appName)
    })
  });

  return response.ok;
}

04 Backend API Endpoints (Express.js)
Backend Routes

Ab hum 4 critical endpoints implement karenge: Register, Verify OTP, Resend OTP, aur Login.

Endpoint 1: POST /api/auth/register

// routes/auth.js
const express = require('express');
const router = express.Router();
const bcrypt = require('bcryptjs');
const jwt = require('jsonwebtoken');
const User = require('../models/User');
const { sendViaBrevoApi } = require('../utils/mailer');

router.post('/register', async (req, res) => {
  try {
    const { email, password, username, displayName } = req.body;

    // 1. Validation
    if (!email || !password || !username || !displayName) {
      return res.status(400).json({ error: 'Saare fields bharna zaroori hai!' });
    }

    const cleanEmail = email.toLowerCase().trim();
    const cleanUsername = username.toLowerCase().trim().replace(/[^a-z0-9_]/g, '');

    // 2. Check agar email pehle se exist karta hai
    const existingUser = await User.findOne({ email: cleanEmail });

    // IMPORTANT EDGE CASE: Agar user pehle register karne aaya tha par OTP verify nahi kiya
    if (existingUser) {
      if (existingUser.isEmailVerified) {
        return res.status(400).json({ error: 'Ye email pehle se registered hai. Please Login karein.' });
      }

      // Re-generate OTP for unverified user and update details
      const salt = await bcrypt.genSalt(10);
      const passwordHash = await bcrypt.hash(password, salt);
      const otp = Math.floor(100000 + Math.random() * 900000).toString();
      const otpExpires = new Date(Date.now() + 10 * 60 * 1000); // 10 mins

      existingUser.username = cleanUsername;
      existingUser.displayName = displayName.trim();
      existingUser.passwordHash = passwordHash;
      existingUser.otpCode = otp;
      existingUser.otpExpires = otpExpires;
      await existingUser.save();

      await sendViaBrevoApi(cleanEmail, otp);
      return res.json({ success: true, message: 'OTP send ho gaya!', email: cleanEmail });
    }

    // 3. New User: Hash password & Generate 6-digit OTP
    const salt = await bcrypt.genSalt(10);
    const passwordHash = await bcrypt.hash(password, salt);
    const otp = Math.floor(100000 + Math.random() * 900000).toString();
    const otpExpires = new Date(Date.now() + 10 * 60 * 1000);

    const newUser = new User({
      id: 'user_' + Date.now(),
      username: cleanUsername,
      email: cleanEmail,
      displayName: displayName.trim(),
      passwordHash,
      isEmailVerified: false,
      otpCode: otp,
      otpExpires
    });

    await newUser.save();
    await sendViaBrevoApi(cleanEmail, otp);

    res.status(201).json({ success: true, message: 'OTP aapke email par bhej diya gaya hai!', email: cleanEmail });
  } catch (err) {
    console.error('Register error:', err);
    res.status(500).json({ error: 'Registration failed. Kripya dubara koshish karein.' });
  }
});

Endpoint 2: POST /api/auth/verify-otp

router.post('/verify-otp', async (req, res) => {
  try {
    const { email, otp } = req.body;
    if (!email || !otp) return res.status(400).json({ error: 'Email aur OTP dono zaroori hain.' });

    const user = await User.findOne({ email: email.toLowerCase().trim() });
    if (!user) return res.status(404).json({ error: 'User nahi mila.' });

    // 1. Check if OTP is expired
    if (!user.otpExpires || new Date() > new Date(user.otpExpires)) {
      return res.status(400).json({ error: 'OTP expire ho chuka hai! "Resend OTP" par click karein.' });
    }

    // 2. Check if OTP matches
    if (user.otpCode !== otp.trim()) {
      return res.status(400).json({ error: 'Galat OTP code! Kripya check karke dubara daalein.' });
    }

    // 3. Mark user verified and clear OTP
    user.isEmailVerified = true;
    user.otpCode = null;
    user.otpExpires = null;
    await user.save();

    // 4. Generate JWT Login Token
    const token = jwt.sign(
      { id: user.id, email: user.email, username: user.username },
      process.env.JWT_SECRET || 'super_secret_jwt_key_123',
      { expiresIn: '7d' }
    );

    res.json({
      success: true,
      message: 'Email successfully verify ho gaya!',
      token,
      user: { id: user.id, username: user.username, email: user.email, displayName: user.displayName }
    });
  } catch (err) {
    console.error('Verify error:', err);
    res.status(500).json({ error: 'Verification failed.' });
  }
});

Endpoint 3: POST /api/auth/login

router.post('/login', async (req, res) => {
  try {
    const { identifier, password } = req.body; // Can be email or username
    if (!identifier || !password) return res.status(400).json({ error: 'Credentials required.' });

    const clean = identifier.toLowerCase().trim();
    const user = await User.findOne({
      $or: [{ email: clean }, { username: clean }]
    });

    if (!user) return res.status(401).json({ error: 'Galat email/username ya password.' });

    // Verify password hash
    const isMatch = await bcrypt.compare(password, user.passwordHash);
    if (!isMatch) return res.status(401).json({ error: 'Galat email/username ya password.' });

    // IMPORTANT: Check if email is verified
    if (!user.isEmailVerified) {
      // Send fresh OTP automatically
      const otp = Math.floor(100000 + Math.random() * 900000).toString();
      user.otpCode = otp;
      user.otpExpires = new Date(Date.now() + 10 * 60 * 1000);
      await user.save();
      await sendViaBrevoApi(user.email, otp);

      return res.status(403).json({
        needsVerification: true,
        email: user.email,
        message: 'Aapka email verify nahi hai. Humne naya OTP bhej diya hai!'
      });
    }

    // Issue JWT
    const token = jwt.sign(
      { id: user.id, email: user.email, username: user.username },
      process.env.JWT_SECRET || 'super_secret_jwt_key_123',
      { expiresIn: '7d' }
    );

    res.json({
      success: true,
      token,
      user: { id: user.id, username: user.username, email: user.email, displayName: user.displayName }
    });
  } catch (err) {
    res.status(500).json({ error: 'Login failed.' });
  }
});
05 Frontend Implementation (React.js)
Client UI Layer

Frontend me hum ek seamless Step-based state machine banate hain: Form Fill → Show OTP Input (with 60s Countdown) → Auto-Login on Success.

// components/AuthModal.jsx
import React, { useState, useEffect } from 'react';

export default function AuthModal({ onLoginSuccess }) {
  // Step: 'login' | 'register' | 'verify_otp'
  const [step, setStep] = useState('register');
  
  // Form Inputs
  const [formData, setFormData] = useState({ email: '', password: '', username: '', displayName: '' });
  const [otp, setOtp] = useState('');
  
  // States
  const [loading, setLoading] = useState(false);
  const [errorMessage, setErrorMessage] = useState('');
  const [cooldown, setCooldown] = useState(60); // 60-second timer for Resend OTP

  // Cooldown countdown timer effect
  useEffect(() => {
    let timer;
    if (step === 'verify_otp' && cooldown > 0) {
      timer = setInterval(() => setCooldown(c => c - 1), 1000);
    }
    return () => clearInterval(timer);
  }, [step, cooldown]);

  // Handle Registration Submit
  const handleRegister = async (e) => {
    e.preventDefault();
    setErrorMessage('');
    setLoading(true);

    try {
      const res = await fetch('/api/auth/register', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify(formData)
      });
      const data = await res.json();

      if (!res.ok) throw new Error(data.error || 'Registration failed');

      // Move to OTP step!
      setStep('verify_otp');
      setCooldown(60);
    } catch (err) {
      setErrorMessage(err.message);
    } finally {
      setLoading(false);
    }
  };

  // Handle OTP Verification Submit
  const handleVerifyOtp = async (e) => {
    e.preventDefault();
    setErrorMessage('');
    setLoading(true);

    try {
      const res = await fetch('/api/auth/verify-otp', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ email: formData.email, otp })
      });
      const data = await res.json();

      if (!res.ok) throw new Error(data.error || 'Invalid OTP');

      // Save Token to LocalStorage!
      localStorage.setItem('auth_token', data.token);
      localStorage.setItem('user_profile', JSON.stringify(data.user));

      onLoginSuccess(data.user, data.token);
    } catch (err) {
      setErrorMessage(err.message);
    } finally {
      setLoading(false);
    }
  };

  return (
    <div className="auth-card">
      {errorMessage && <div className="alert-error">{errorMessage}</div>}

      {step === 'register' && (
        <form onSubmit={handleRegister}>
          <h2>Create an Account</h2>
          <input 
            type="text" 
            placeholder="Full Name" 
            value={formData.displayName} 
            onChange={e => setFormData({...formData, displayName: e.target.value})} 
            required 
          />
          <input 
            type="text" 
            placeholder="Username (e.g. rahul_99)" 
            value={formData.username} 
            onChange={e => setFormData({...formData, username: e.target.value})} 
            required 
          />
          <input 
            type="email" 
            placeholder="Email Address" 
            value={formData.email} 
            onChange={e => setFormData({...formData, email: e.target.value})} 
            required 
          />
          <input 
            type="password" 
            placeholder="Password (min 6 chars)" 
            value={formData.password} 
            onChange={e => setFormData({...formData, password: e.target.value})} 
            required 
          />
          <button type="submit" disabled={loading}>
            {loading ? 'Sending OTP...' : 'Register & Send Code'}
          </button>
        </form>
      )}

      {step === 'verify_otp' && (
        <form onSubmit={handleVerifyOtp}>
          <h2>Enter Verification Code</h2>
          <p>We have sent a 6-digit code to <strong>{formData.email}</strong></p>
          <input 
            type="text" 
            maxLength={6} 
            placeholder="123456" 
            value={otp} 
            onChange={e => setOtp(e.target.value)} 
            style={{ fontSize: '24px', letterSpacing: '6px', textAlign: 'center' }} 
            required 
          />
          <button type="submit" disabled={loading}>
            {loading ? 'Verifying...' : 'Verify & Continue'}
          </button>

          <div className="resend-box">
            {cooldown > 0 ? (
              <span>Resend code in {cooldown}s</span>
            ) : (
              <button type="button" onClick={handleRegister}>Resend OTP</button>
            )}
          </div>
        </form>
      )}
    </div>
  );
}
06 Security & Real-World Production Checklist
Best Practices
🛡️ Production Security Checklist: Ye 6 rules hamesha yaad rakhein jab bhi aap kisi client ya company ke liye authentication banayein:
  1. Rate Limiting Lagayein: express-rate-limit use karein taaki koi hacker script chala kar 10,000 baar OTP guess (Brute-Force) na kar sake. Ek IP se max 5 attempts allow karein.
  2. OTP Expiry Short Rakhein: OTP hamesha 5 se 10 minute ke andar expire hona chahiye (kabhi bhi 1 din ya unlimited mat rakhna).
  3. Single-Use OTP: Jaise hi OTP ek baar verify ho jaye, database se otpCode = null kar dein taaki dobara wahi code use na ho sake.
  4. Timing-Attack Safe Comparison: Password compare karne ke liye hamesha bcrypt.compare() use karein, normal === nahi.
  5. JWT Secret in Environment Variable: JWT_SECRET ko code me hardcode mat karein, hamesha .env file me rakhein.
  6. CORS Configuration: Backend me cors({ origin: 'https://yourdomain.com' }) set karein taaki koi unauthorized website aapki API call na kar sake.
