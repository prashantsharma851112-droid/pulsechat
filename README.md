# ⚡ PulseChat - Next Gen Real-Time Messaging Platform

PulseChat is a modern WhatsApp alternative built with **Node.js, Express, Socket.io, and React**.

## 🌟 Key Features
- ❌ **No Phone Number Login**: Register using Email, Password & Unique `@username`.
- 🖼️ **Profile DP Change System**: Choose preset avatars or upload custom image URLs + Status/Bio editor.
- 🎨 **Multi-Theme Engine**: Dark Mode, Light Mode, Emerald Green (WhatsApp Classic), Cyberpunk Neon & Sunset Rose.
- 🎙️ **Voice Notes**: Integrated mic recording with live playback.
- ⚡ **Real-Time WebSockets**: Instant message streaming & online/offline presence.
- ✔️✔️ **Read Receipts**: Single tick (Sent), Gray double tick (Delivered), Blue double tick (Read).
- ✍️ **Typing Indicators**: Live "...is typing" alerts.
- 😀 **Emoji Reactions**: React directly to any message.
- 📞 **Voice/Video Call Simulation**: Interactive overlay with mic/video toggles.

## 🚀 How to Run locally

### Step 1: Start Backend Server
```bash
cd backend
npm install
npm run dev
```
*Backend will run on http://localhost:5000*

### Step 2: Start Frontend App
```bash
cd frontend
npm install
npm run dev
```
*Frontend will run on http://localhost:5173*
